What Is a Screenshare?

A screenshare (SS) is an anti-cheat check where a server staff member remotely inspects a suspect player's PC using forensic tools to determine whether they are using unauthorized modifications (hacked clients, autoclickers, macros, etc.). Server-side anticheat alone cannot catch everything — screensharing fills that gap.

// Purpose

Why SS?

  • Detect hacked clients that bypass server AC
  • Find autoclickers & hardware macros
  • Uncover ghost clients & RAM-injected cheats
  • Maintain fair play on competitive servers
// Ethics

SS Principles

  • Only SS with consent per your server rules
  • Don't ban based on false positives alone
  • Cross-verify with multiple evidence sources
  • Save logs/screenshots before banning
// Evidence

Bannable Evidence

  • Active cheat client in memory / prefetch
  • Cheat client folder in AppData
  • Injected DLL into javaw.exe
  • Macro profiles in mouse software
  • Positive automated tool verdict

Key Windows Forensic Artifacts

PREFETCH Program Execution Evidence
What it is: Windows stores .pf files every time an executable runs, capturing the program name, run count, last 8 run timestamps, and DLLs/paths referenced. Files persist even after the executable is deleted. C:\Windows\Prefetch\CHEATCLIENT.EXE-XXXXXXXX.pf How to check: Chicho [10], WinPrefetchView (NirSoft), Spok's Prefetch Parser (PECmd). Look for injector names, cheat client names, or suspicious executables. Check the referenced paths — they may point to deleted files.
// BANNABLE INDICATOR A .pf file for a known cheat client exe, or a prefetch file referencing a cheat .jar file from the mods folder.
BAM — Background Activity Moderator Execution Registry
What it is: A Windows registry key that logs executables that have run. Useful because it includes last execution timestamps and survives program deletion. HKLM\SYSTEM\CurrentControlSet\Services\bam\State\UserSettings\<SID>\ How to check: Chicho [BAM], Spok's BAM Parser, or run the RedLotus BAM PowerShell script. Look for cheat-named executables.
SHIMCACHE / AMCACHE Additional Execution Evidence
Shimcache: Registry entry logging executables Windows has encountered or executed. Includes file path. Amcache.hve: More detailed — stores file paths, SHA1 hashes, and timestamps of recently executed programs. Can prove a cheat existed even if every other trace is gone. HKLM\SYSTEM\CurrentControlSet\Control\Session Manager\AppCompatCache C:\Windows\AppCompat\Programs\Amcache.hve
SHELL:RECENT Recently Opened Files
What it is: A folder of shortcuts to recently opened files and folders. Opened with shell:recent or via Start → Run. Shows what files the suspect has been accessing — useful for finding cheat-related files they tried to hide. C:\Users\<username>\AppData\Roaming\Microsoft\Windows\Recent How to check: Chicho [5], or manually open via Win+R → shell:recent. Look for recently opened .jar, .exe, or .zip files outside of legitimate software.
NTFS USN JOURNAL File System Activity
What it is: The Windows NTFS journal records file creation, modification, and deletion events at a system level. A cheat that "self-destructs" still leaves a trace in the journal because the deletion itself is logged. How to check: Chicho [D] USN Journal, Spok's JournalTrace, or: fsutil usn readdata C: 0 2048
// BANNABLE INDICATOR USN Journal entry showing a cheat-named file was created and then deleted recently — classic self-destruct behavior.
BROWSER DOWNLOADS Download History
What it is: Browsers (Chrome, Edge, Brave, Firefox) keep a SQLite database of every file ever downloaded, including files that were later deleted. Shows filename, URL source, timestamp, and whether the file still exists on disk. %LOCALAPPDATA%\Google\Chrome\User Data\Default\History How to check: Chicho [BF] Browser Forensics → Downloads. Look for downloaded .jar, .exe, .zip files. A deleted cheat that shows as [DELETED] in the downloads list but with a cheat-related filename is strong evidence.
APPDATA FOLDERS Cheat Client Residue
What it is: Many cheat clients create their own folder in AppData/Roaming or AppData/Local — even after the client itself is deleted, the config folder often remains. %APPDATA%\<ClientName>\ or %LOCALAPPDATA%\<ClientName>\ How to check: Chicho [1] and [S], or manually browse AppData. Note: Prestige client requires a Windows Firewall whitelist — check [7] Hosts file and firewall rules.

SS Workflow — Step by Step

// BEFORE YOU START Make the suspect close Minecraft BEFORE you connect. A running ghost client can wipe itself when it detects remote access or an unexpected disconnect.

Establish Remote Access

  • Have suspect download AnyDesk / AnyViewer
  • Request full control
  • Tell them to close Minecraft and all recording software
  • Check their screen isn't being mirrored (look for unusual lag/artifacting = possible VM)

Initial Environment Check

  • Run Chicho SS Helper as Administrator
  • Check [I] Recording Scanner — kill OBS/Bandicam/Shadowplay if found
  • Check [13] VPN / Virtual Adapters — note any VPNs or VM adapters
  • Run [2] Running Processes — look for suspicious process names and Java injection

Run Automated Scans

  • [18] Full Auto Scan in Chicho SS Helper — covers all built-in checks
  • Run Ocean Anti-Cheat — give suspect the link, collect PIN, lookup results via [O]
  • Run RedLotus PowerShell BAM script (lists unverified programs)
  • Launch [EXT] External Tools → MeowModAnalyzer for PE/signature scan

Forensic Artifact Review

  • [10] Prefetch — search for cheat-named .pf files
  • [BAM] — check execution history in registry
  • [5] shell:recent — recently opened suspicious files
  • [D] USN Journal — look for recently created & deleted files (self-destructs)
  • [BF] Browser Downloads — check for deleted .jar/.exe downloads

Minecraft-Specific Checks

  • [3] .minecraft folder — check mods, versions, latest.log
  • [K] Launcher Scanner — check Prism, Lunar, Badlion, TLauncher etc.
  • [M] Java Arguments — look for -javaagent, -tweakclass, unexpected agents
  • [JP] JAR Parser — deep bytecode scan of mod JARs for cheat signatures
  • Check launcher_profiles.json for non-standard Java paths or suspicious version IDs

Macro / Input Device Check

  • [H] Macro Scanner — checks Logitech, Razer, SteelSeries, ASUS ROG, Corsair, etc.
  • [EXT] ShadowClicker (MeowTonynoh) — dedicated autoclicker detector
  • Check mouse software config folders manually for macro profiles
  • Run USBDeview (NirSoft) via [A] Manual Tools — check for suspicious USB devices

Advanced Checks (if needed)

  • [BYP] Bypass Detector — check for anti-forensic tools (CCleaner, timestamp modifiers, etc.)
  • [FF] File Forensics — deep scan + VirusTotal for suspicious files
  • [NW] Novoware Scanner — RAM scan for Novoware cheat signatures
  • Process Hacker / System Informer — manually check javaw.exe loaded DLL list
  • [G] Event Viewer — check for suspicious event log entries

Save Report & Verdict

  • Run [R] Save Full Scan Report — dumps all results to Desktop
  • Screenshot key evidence before closing
  • Log HWID via [J] HWID Extractor
  • Cross-verify findings — don't ban on a single uncertain indicator
  • If banning: record session video, save report file, document everything

On-Board Macro Devices

Stored on the mouse/keyboard itself — doesn't require software:

  • Check USB device history via USBDeview
  • Chicho [D] can detect injected USB devices
  • Look for unusual HID devices in Device Manager
  • Some use custom USB hubs to hide secondary devices
// Detection Tips

What to Check

  • Profile files in mouse software AppData folders
  • Macro folder under each software's data directory
  • Run ShadowClicker ([EXT]) for automated detection
  • Check debounce time (normal: 10–25ms; cheating: <2ms)

  • Razer: %APPDATA%\Razer\Synapse3\Settings\
// IMPORTANT — Debounce Abuse Many servers ban for debounce times under a threshold (varies by server, typically <4ms or <10ms). Check your server's specific rule on this before issuing a ban.

Common Bypass Techniques

Cheaters may try to destroy evidence or confuse your checks. Knowing these helps you counter them — and some are ban-worthy on their own if your server rules say so.

// Evidence Destruction

Self-Destruct / File Wipe

  • Client deletes itself when game closes
  • CCleaner run before SS
  • Prefetch disabled (check in settings)
  • Event log cleared

Counter: USN Journal, BAM, browser downloads, Amcache all persist past file deletion. Check [BYP] for anti-forensic tool traces.

// Execution Hiding

Prefetch Disable / Timestamp Spoof

  • Disabling prefetch via registry
  • Modifying file timestamps
  • Unicode chars in filenames to evade string matching
  • Packing/obfuscating cheat JARs

Counter: Prefetch being disabled is itself suspicious. Use [JP] JAR Parser for bytecode-level detection. Unicode Detector (in RedLotus tools) catches unicode-named files.

// Environment Hiding

VM / Remote Desktop

  • Running Minecraft in a VM so SS sees clean host
  • Unusual screen latency / blurring artifacts
  • VMware, VirtualBox adapters in Device Manager
  • Hyper-V indicators

Counter: Chicho [13] checks for virtual network adapters. Check msinfo32 [30] for hardware info. VMs often lack GPU and show generic display adapters.

// Connection Hiding

VPN During SS

  • Running a VPN while being screenshared
  • Can indicate suspicion or privacy concern

Action: Your .bat asks whether to continue if Windscribe/PIA/ProtonVPN/IPVanish is detected. Per server rules, this may require the suspect to disconnect the VPN or be treated as a refusal to SS.

// RAM Injection

Ghost Clients

  • Injected directly into javaw.exe memory
  • No files on disk at all
  • Loaded via a separate injector process that was then killed

Counter: Use [NW] Novoware RAM scanner, Process Hacker DLL list for javaw.exe, and injector names in Prefetch.

// Hosts File

Blocked Sites / Firewall

  • Blocked cheat-detection sites in hosts file
  • Windows Firewall rules for cheat client whitelisting (e.g. Prestige)

Counter: Chicho [7] opens hosts file in Notepad. Check Windows Firewall rules via [33] or manually in Windows Security.

📋 Verdict & Evidence Standards

// Definitive Ban

Strong Evidence

  • Active cheat client in process list
  • Cheat DLL injected into javaw.exe
  • Positive Ocean AC / auto-tool verdict
  • Cheat-named .pf in Prefetch + file deleted
  • Cheat client config folder in AppData
  • Cheat .jar confirmed in mods folder
  • Cheat signatures found in RAM
// Supporting Evidence

Suspicious Indicators

  • Browser downloads show deleted cheat .exe/.jar
  • USN Journal shows recently deleted cheat file
  • BAM shows cheat-named execution recently
  • Macro profile found in mouse software
  • Prefetch disabled / event logs cleared
  • Non-standard Java paths in launcher profiles
  • Obfuscated .jar in mods folder (server policy dependent)
// Best Practice

Before Banning

  • ✔ Cross-verify with 2+ independent evidence sources
  • ✔ Save the full report ([R] in Chicho)
  • ✔ Screenshot key evidence
  • ✔ Record the session if possible
  • ✔ Log their HWID ([J]) for future reference
  • ✔ Follow your server's ban policy exactly
